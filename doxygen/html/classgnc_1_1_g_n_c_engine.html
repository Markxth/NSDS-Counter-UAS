Detailed Description

Handles GNC engine orchestration.

GNCEngine is responsible for orchestrating the execution of various components of the Guidance, Navigation, and Control code. GNCEngine's primary public interface is the receive_target_packages method which receives a list of target packages and then makes choices about which target to prioritize and executes the necessary code to acquire that target.
