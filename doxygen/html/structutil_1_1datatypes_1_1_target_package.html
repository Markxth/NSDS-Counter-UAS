Detailed Description

Contains data about a single possible target as determined by the sensor systems.

The TargetPackage stores vectors in rotated xyz coordinates. These rotated vectors are found by takeing the screen space coordinates (and range) of a target and converting them into xyz coordinates with the camera assumed to be at the origin with no rotation. In actuality, the camera likely has some rotation, which means the 'rotated' vectors are not the same in the fixed frame. 'Rotated' vectors can be converted into fixed frame vectors using the known orientation of the camera.
