\doxysubsection{Detailed Description}
Handles the navigation logic for the C-\/\+UAS GNC system. 

The \doxylink{classgnc_1_1_navigation_engine}{Navigation\+Engine} is responsible for determine the current state of the turret relative to its base state and surroundings. Internally the \doxylink{classgnc_1_1_navigation_engine}{Navigation\+Engine} listens to IMUs and rotary encoders in the turret structure to determine the current state, and may use GIS information to augment state measurements.
