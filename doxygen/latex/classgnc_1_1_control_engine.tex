\doxysubsection{Detailed Description}
Handles the control logic for the C-\/\+UAS GNC system. 

The \doxylink{classgnc_1_1_control_engine}{Control\+Engine} receives a target location and emits hardware signals to align the turret to it. Internally it runs a PID loop that estimates and corrects aiming error from external forces such as wind and recoil. Error is in radians of turret deflection. Ported from pycode/\+gnc/\+controls.\+py.
