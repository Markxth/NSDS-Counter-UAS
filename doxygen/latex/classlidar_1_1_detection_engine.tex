\doxysubsection{Detailed Description}
Handles target detection for the C-\/\+UAS Li\+DAR system. 

The \doxylink{classlidar_1_1_detection_engine}{Detection\+Engine} is responsible for evaluating candidate clusters, rejecting those unlikely to be UAS, and converting the remainder into target measurements (position, extent, and timestamp) for sensor fusion.
