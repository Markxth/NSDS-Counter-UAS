\doxysubsection{Detailed Description}
Handles GNC engine orchestration. 

\doxylink{classgnc_1_1_g_n_c_engine}{GNCEngine} is responsible for orchestrating the execution of various components of the Guidance, Navigation, and Control code. \doxylink{classgnc_1_1_g_n_c_engine}{GNCEngine}\textquotesingle{}s primary public interface is the receive\+\_\+target\+\_\+packages method which receives a list of target packages and then makes choices about which target to prioritize and executes the necessary code to acquire that target.
