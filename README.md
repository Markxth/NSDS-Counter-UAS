# Purdue National Security and Defense Society: Counter Unmanned Aerial Systems - MOVED TO A DIFFERENT DIRECTORY

Software and firmware for the Purdue NSDS C-UAS platform.

## About the Project

In an effort to enhance the understanding of the field, increase the variety of options on the market, and support US DoW interests, the
Purdue National Security and Defense Society has set out to build a Counter Unmanned Aerial Systems platform. This repository hosts the software
and firmware for the C-UAS platform.

## Getting Started

To get started with a local copy:
1. Fork or clone the repository
2. Build the repository's C++ (cpp_code/) code using CMake

## Contributing

To begin contributing:
1. Fork the repository
2. Create feature branch ('git checkout -b some-feature)
3. Add and commit changes ('git add . && git commit -m "add some feature"')
4. Push to branch ('git origin push some-feature')
5. Open a Pull Request ('Pull Requests -> New Pull Request')
